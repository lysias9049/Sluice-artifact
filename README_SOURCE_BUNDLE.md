# RW-Groth16 Source Bundle

This directory contains the RW-Groth16 Rust prototype source code, benchmark
drivers, tests, and compact experiment CSV/log metadata.

Large generated artifacts are intentionally excluded from source handoff
archives:

- `target/`
- `target-linux/`
- `.cargo-linux/`
- `Experiments/*_data/`
- `Experiments/archive/`
- long-running local log directories

These files can be regenerated by the experiment scripts when needed.

## Build

```bash
cargo build --release
```

## Tests

```bash
cargo test --release
```

## Main Binaries

- `streaming_bench`: main standard/RW/RW-File benchmark driver.
- `rw_prove_only`: materialize and run clean RW-RW prove-only experiments.
- `std_prove_only`: materialize and run clean standard prove-only experiments.
- `real_workload_bench`: structured MiMC-style Merkle workload sanity check.
- `production_baseline_bench`: native arkworks Groth16 baseline on the same
  structured workload family.

## Important Experiment Notes

The main bounded-memory reproduction script is:

```bash
./Experiments/run_cgroup_n23.sh verify
```

The low-memory engineering sweep script is:

```bash
./Experiments/run_rw_lowmem_sweep.sh 20 32m,48m,64m,96m,128m
```

See `Experiments/README_ARTIFACT.md` for paper/artifact mapping and exact
experiment commands.
